# Cursed Faction NFT Vault Crypto Assets Tree Branch System

The **Cursed Faction NFT Vault Crypto Assets Tree Branch System** is an innovative platform for managing, banking, and branching NFT-linked crypto assets. Each NFT acts as a vault, enabling secure deposits and withdrawals, with a dynamic tree branch system for collaborative savings, gifting, and in-game functionality. This system supports advanced asset management and branching strategies for NFT collectors and gamers.

---

## 🏰 Legacy: MMO Backend Services

Originally, this repository was created as a monorepo for MMO backend services, including:

- **API Gateway:** Central entry point for client-server communication
- **Matchmaking:** Real-time matching of players for sessions and games
- **Session Management:** Handles user sessions and game state
- **Inventory Management:** Player inventory and asset management

These services provide a robust foundation for scalable multiplayer and NFT banking experiences. Historical branches or documentation may contain more details.
